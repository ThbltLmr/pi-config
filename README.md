# pi-config

Personal configuration for [Pi](https://pi.dev).

## Included

- Catppuccin Frappe theme
- User-invoked skills:
  - `/skill:handoff`
  - `/skill:grill-me`
  - `/skill:grill-with-docs`
  - `/skill:teach-me`
- Prompt templates:
  - `/atomic-commit`
  - `/catchup`

This repository intentionally excludes local auth tokens, sessions, trust state, and package caches.
